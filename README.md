# Lucky Bike

Website und Backoffice für eine Werkstatt für E-Motorräder, E-Bikes und E-Roller.

- Next.js 16 (App Router, TypeScript), Tailwind CSS 4, GSAP (ScrollTrigger, DrawSVG)
- Design-Richtung: [docs/design.md](docs/design.md)
- Claude-Skills für das Projekt: [.claude/skills](.claude/skills/README.md)

## Lokal starten

```bash
npm install
npm run dev
```

Dann http://localhost:3000 öffnen.

## Stand

Startseite mit Explosionszeichnung (Leistungen), Ablauf, Fahrzeugen, Ersatzteil-Vorschau und Kontakt.
Texte, Preise, Adresse und Telefonnummer sind Platzhalter. Buchung, Shop und Backoffice folgen.
